# esp32-servo-signal-filter
ESP32-based servo control system with digital signal filtering (RAW, Moving Average, Median, Exponential and Auto modes), OLED interface and Wokwi simulation.
# ESP32 Servo Signal Filter

A mechatronics project demonstrating digital signal processing for servo control.

## Features

- ESP32
- SG90 Servo
- OLED SSD1306
- Potentiometer input
- Push button interface
- RAW mode
- Moving Average filter
- Median filter
- Exponential filter
- Automatic filter selection (AUTO)
- Logic Analyzer support (Wokwi)

## Hardware

- ESP32 DevKit V1
- SG90 Servo
- SSD1306 OLED 128x64
- 10k Potentiometer
- Push Button

## Software

- Arduino IDE
- ESP32Servo
- Adafruit GFX
- Adafruit SSD1306
- Wokwi Simulator

## Project Goal

The project demonstrates the influence of different digital filtering algorithms on analog signal processing and servo positioning accuracy.
